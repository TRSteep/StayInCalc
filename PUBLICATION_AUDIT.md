# Проверка перед публикацией — 25.10.2026

Проверен репозиторий GitHub `TRSteep/StayCalc`. GitLab remote не настроен.
На момент проверки репозиторий приватный; опубликованных релизов, Issues,
артефактов Actions и Wiki нет. На origin обнаружена только ветка main, без тегов.

- Gitleaks v8.30.1: проверены текущие файлы и вся доступная история origin
  (18 коммитов на момент исходного аудита). Совпадений по правилам поиска секретов нет.
  Сканер загружен из официального релиза, архив проверен по SHA-256.
- Дополнительно просмотрен 131 вариант файлов в истории origin: профили,
  settings.json, файлы ключей и .env не найдены. Проверены email, локальные
  пути пользователя и частные IP в содержимом файлов, включая ресурс syso;
  подтверждённых совпадений нет. Тестовые имена и поездки являются фикстурами.
- После исходного аудита выполнено обезличивание опубликованной истории:
  имя автора/коммитера заменено на публичный псевдоним TRSteep, email —
  на официальный GitHub noreply-адрес. Обновлены main и тег релиза v1.0.2.
  Для будущих коммитов в этом репозитории также настроен noreply-адрес.
  Содержимое файлов и даты исторических коммитов сохранены.
  Локальная резервная копия прежней истории находится в игнорируемой папке release;
  её нельзя публиковать. Старые SHA могут сохраняться в кэшах GitHub и внешних копиях;
  смена доступной истории не гарантирует удаления этих копий.
- Проверка свежей копии с GitHub подтвердила обезличивание main и v1.0.2.
  Однако доступность прежнего коммита по прямому SHA через GitHub API
  подтверждена: он всё ещё содержит прежний личный email. Репозиторий оставлен
  приватным. Для полного удаления старых объектов подготовлен локальный черновик
  обращения `release/privacy-backup/SUPPORT_REQUEST.md`; он не опубликован.
  [Документация GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)
  описывает очистку кэшей и объектов через поддержку; удовлетворение запроса
  об удалении личного email не гарантировано. Старые копии не следует сливать
  в новую историю: это может вернуть прежние коммиты.
- Личные профили и настройки исключены через .gitignore. Релиз собирается
  по явному списку файлов, с `-trimpath -buildvcs=false`, без пользовательской data.
- Архив v1.0.2 проверен: Windows x64 GUI EXE, 47 файлов, стандартные правила
  совпадают с исходными. Профилей, settings.json и реальных локальных путей
  разработчика в EXE нет. Динамические зависимости — системные DLL Windows/OpenGL;
  отдельные DLL MinGW не требуются. Тесты `go test -tags ci ./...` и `go vet -tags ci ./...` прошли.

Автоматический поиск не гарантирует отсутствие всех видов конфиденциальных
данных. Проверка относится к доступному origin и локальному состоянию;
не охватывает неизвестные зеркала GitLab, удалённые недоступные refs и внешние копии.
