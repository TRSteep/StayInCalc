# StayCalc — калькулятор пребывания в стране

GUI-программа на Go (Fyne) для учёта дней пребывания: сколько дней уже прошло,
сколько осталось и до какой даты нужно выехать. Для машины предусмотрен отдельный учёт поездок и условий ввоза.

## Запуск
`StayCalc.exe` — данные хранятся в папке `data` рядом с exe:

```
data/
  countries.json        правила по странам (редактируются)
  settings.json         последний открытый профиль
  profiles/Иван.json    профиль = один человек (член семьи)
  profiles/Мария.json
```

## Как пользоваться
1. «Новый» — создать профиль (имя + выбор гражданства, например «Россия (RU)»). Для каждого члена семьи — свой профиль.
2. Выбрать страну.
3. Ввести даты въезда/выезда (ДД.ММ.ГГГГ или кнопкой календаря). Когда заполнен выезд в последней строке,
   автоматически появляется новая строка. Пустой выезд = вы ещё в стране.
4. Отметить «Регистрация», если выполнены указанные в правиле условия учёта/уведомления или одобрено продление.
5. Вкладка «Автомобиль» — отдельные даты для машины (или «Скопировать даты из поездок»).
   Здесь же выбирается страна регистрации авто (страна номеров); она сохраняется
   в профиле отдельно от гражданства. Основной сценарий — туристическая поездка без ВНЖ.
6. Справа: использованные дни, остаток по каждому лимиту, **последний допустимый день**, ближайшая
   дата возможного въезда, нарушения в истории, срок регистрации, число въездов (визаранов).

«Расчёт на дату» позволяет посчитать на любой день, в т.ч. спланировать будущий въезд.

Над всеми карточками отображается заголовок **страна — пользователь (гражданство)**.
Далее идут **общая информация**, выделенная дата выезда, пребывание на дату расчёта
и автомобиль (если введены его даты). В карточке со сроком выезда
показаны варианты возвращения минимум на **14 дней** и **30 дней** (месяц).
Для каждого варианта указаны дата въезда, последний день целевого срока и число
полных дней вне страны. Расчёт предполагает выезд на дату расчёта («сегодня») и отсутствие
других поездок; если регистрация/продление позволяет вернуться раньше, это условие
подписано. День выезда и день возвращения не входят в число полных дней вне страны.

История изменений — в [CHANGELOG.md](CHANGELOG.md).

Ошибочные даты, выезд раньше въезда и пересекающиеся поездки останавливают расчёт
сообщением об ошибке. Выезд и повторный въезд в один день разрешены. Незавершённый
ввод даты сохраняется как черновик; после исправления расчёт возобновляется.
У одноимённых профилей в списке дополнительно показывается имя файла.
При запуске открывается последний выбранный профиль. Если он удалён, выбирается
первый доступный. Настройки выбора хранятся в `data/settings.json` и не попадают в Git.

История проверяется с учётом регистрации/продления каждой поездки. При поиске
следующего въезда учитывается годовой лимит въездов; продление прошлой поездки
не переносится на новую. Прогноз предполагает непрерывное пребывание после въезда.
Горизонт поиска — около трёх лет: если предел не найден, программа сообщает об этом,
а не показывает границу расчёта как обязательную дату выезда.

## Правила (`countries.json`)
Редактируются кнопкой «Правила стран» (с проверкой) или в любом текстовом редакторе.
Правила РФ проверены **25.10.2026** для обычных паспортов и кратких поездок:
[источники, условия и ограничения расчёта](RULES_RU.md). Для остальных гражданств
сохранены непроверенные примеры. 0 = нет заданного числового ограничения.
В правилах РФ для автомобиля включена индивидуальная проверка `vehicle.manual`:
история отображается, а дата обязательного вывоза определяется по документам ввоза.

| Поле | Смысл |
|---|---|
| `citizenships` | для каких гражданств правило (`"*"` — для остальных) |
| `visa_required`, `visa_note` | нужна ли виза |
| `max_consecutive` | максимум дней подряд |
| `max_consecutive_months` | максимум календарных месяцев за въезд (12 — полный год) |
| `max_in_period` + `period_days` | скользящий период, напр. 90 из 180 |
| `max_per_year` + `year_mode` | лимит в году: `calendar` или `rolling` (365 дней) |
| `visa_run.allowed`, `min_days_outside`, `max_per_year` | обнуляет ли выезд счётчик «подряд», сколько дней надо быть вне страны, лимит въездов в год |
| `registration.required`, `within_days` | нужна ли регистрация и в какой срок |
| `registration.extends_stay`, `extended` | увеличивает ли срок и какие лимиты с регистрацией |
| `vehicle` | лимиты временного ввоза машины (те же поля) |
| `vehicle.manual`, `source` | индивидуальная проверка срока автомобиля и её источник; `manual=true` отключает автоматическую дату вывоза |
| `history` | прежние лимиты и условия регистрации по дате въезда, с границей `before` (не включая эту дату) |

Страна может быть зоной с общим счётчиком (пример — `SCHENGEN`).

## Сборка
Нужны Go и gcc (MinGW/MSYS2 ucrt64), т.к. Fyne использует cgo:
```
set CGO_ENABLED=1
go build -ldflags "-H=windowsgui -s -w" -o StayCalc.exe .
go test .
```

Для проверки без графического драйвера: `go test -tags ci ./...` и `go vet -tags ci ./...`.

## Иконка
- `assets/icon.png`, `assets/icon.ico` — иконка (генерируется `python assets/mkicon.py assets`).
- Иконка окна вшита в exe через `go:embed` (`assets/icon256.png`).
- Иконка exe — ресурс `rsrc_windows_amd64.syso`, Go подхватывает его при сборке автоматически.
  После замены `assets/icon.ico` пересоберите его:
```
windres -O coff -o rsrc_windows_amd64.syso assets/app.rc
```

## Git
Папка `data/profiles/` (личные данные — даты поездок) исключена через `.gitignore`
и в репозиторий не попадает. Её резервную копию делайте отдельно. Собранный `StayCalc.exe` тоже не хранится в git.
